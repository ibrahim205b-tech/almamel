# إشعارات دليل المعامل

الي يفعّل الإشعارات من الموقع توصله إشعارات باسم «دليل المعامل»، حتى لو الموقع مسدود:
- **الأخبار:** أول ما يتوافق على خبر (بالكثير ٦ إشعارات أخبار باليوم).
- **رسائل تنبيهية مرتبة:** وحدة كل ٣ أيام بالكثير، الساعة ٧:١٣ مساءً بتوقيت بغداد. مثلاً «عندك بيت للإيجار؟ اعرضه بدليل المعامل».
- **إشعار منك:** من لوحة الإدارة، قسم «الإشعارات».

الموقع يطلب السماح بلطف: يطلع شريط صغير بالزيارة الثانية أو بصفحة الأخبار، ومن يضغط «لاحقاً» ما يطلع إله أسبوع.

**ملاحظة الآيفون:** إشعارات الويب على الآيفون تشتغل بس إذا الموقع مثبّت على الشاشة الرئيسية (iOS 16.4 وأحدث)، والشريط يشرح هالشي للزائر.

## التركيب (مرة وحدة)
1. **شغّل** `supabase/updates/2026-11-push.sql` بالـ SQL Editor.
2. **شغّل سطر المفتاح السري** الي وصلك بالمحادثة (يبدي بـ `insert into private.secrets ... 'vapid_private'`). هذا المفتاح ما ينحفظ بأي ملف بالمشروع.
3. **ارفع الدالة:**
   1. روح على Edge Functions، واضغط Deploy a new function، واختار Via Editor.
   2. الاسم بالضبط `push`، والصق محتوى `supabase/functions/push/index.ts`، واضغط Deploy.
   3. **طفّي** خيار Verify JWT.
4. **جرّب:**
   1. فعّل الإشعارات من الموقع على موبايلك.
   2. من لوحة الإدارة، قسم «الإشعارات»، اكتب إشعار واضغط «إرسال لكل المشتركين».

## تعديل الرسائل التنبيهية
بالـ SQL Editor:
```
select * from push_promos order by sort;                                  -- تشوفها
update push_promos set body = 'نص جديد' where id = 1;                      -- تعدّل
insert into push_promos (title, body, url, sort) values ('عنوان', 'نص', '/jobs/', 9);  -- تضيف
update push_promos set active = false where id = 3;                        -- توقف وحدة
```
