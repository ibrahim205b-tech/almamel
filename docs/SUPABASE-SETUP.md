# تفعيل الإعلانات المباشرة وحسابات أصحاب المحلات (Supabase مجاناً)

الموقع يبقى على GitHub Pages مجاناً. Supabase (مجاني، بلا بطاقة) يحفظ الإعلانات والحسابات والقوائم.
كل ربع ساعة يتحقق GitHub من وجود جديد معتمد ويحدّث الموقع. هذا الفحص نفسه يُبقي مشروع Supabase نشطاً (المشاريع المجانية تتوقف بعد أسبوع بلا نشاط).

## الخطوات (مرة واحدة)

1. **إنشاء المشروع:** ادخل supabase.com ← **Start your project** ← سجّل بحساب GitHub.
   ثم **New project**: الاسم `almamel`، كلمة مرور لقاعدة البيانات (احفظها عندك)، المنطقة **Frankfurt (eu-central-1)**، الخطة **Free** ← **Create new project**. انتظر دقيقتين.
2. **إنشاء الجداول وقواعد الأمان:** من القائمة الجانبية **SQL Editor** ← **New query**.
   افتح الملف `supabase/schema.sql` في GitHub، اضغط **Copy raw file**، الصقه، ثم **Run**. يجب أن تظهر **Success**.
3. **البريد الإلكتروني:** **Authentication** ← **Sign In / Providers** ← **Email** ← أطفئ **Confirm email** ← **Save**.
   (الخطة المجانية ترسل عدداً قليلاً جداً من الرسائل بالساعة، والتحقق من المحل يتم بالاتصال على رقمه أصلاً.)
4. **روابط الموقع:** **Authentication** ← **URL Configuration**:
   - **Site URL:** `https://ibrahim205b-tech.github.io/almamel/`
   - **Redirect URLs:** أضف `https://ibrahim205b-tech.github.io/almamel/login/`
5. **المفاتيح:** **Project Settings** ← **API Keys** (أو **Data API**). انسخ:
   - **Project URL** (مثل `https://abcd1234.supabase.co`)
   - المفتاح العام **publishable** (يبدأ بـ `sb_publishable_`) أو **anon public**.
   ضعهما في ملف `site.config.json` في المستودع (أو أرسلهما للمطوّر).
   **لا تشارك أبداً** المفتاح السري (`sb_secret_` أو `service_role`). البناء يرفضه تلقائياً إذا وُضع بالخطأ.
6. **حساب المدير:** من الموقع افتح `/owner/register/` وأنشئ حسابك (الخطوة الأولى فقط تكفي)،
   ثم في **SQL Editor** شغّل (مع بريدك):
   ```sql
   select public.make_admin('your-email@gmail.com');
   ```
   بعدها ادخل من `/login/` فتفتح **لوحة الإدارة**.

## كيف يعمل

- **إعلانات الزوار:** «أضف إعلانك» يرسل الإعلان مباشرة بحالة «بانتظار المراجعة». حد أقصى ٣٠ إعلان زائر بالساعة لكل الموقع، و٣ صور لكل إعلان.
- **أصحاب المحلات:** `/owner/register/` ← حساب + معلومات المحل + إثبات (صورة خاصة بمخزن مغلق لا يراه إلا المدير).
- **المدير:** `/admin/` ← «بانتظار المراجعة» (موافقة أو رفض)، و«طلبات أصحاب المحلات» (يرى صورة الإثبات ويتصل بالرقم ثم يعتمد فينشر المحل)، و«المنشور حالياً» (إخفاء، حذف، توثيق).
- **صاحب المحل المعتمد:** `/owner/dashboard/` ← قائمة الطعام بأقسام وصور وأسعار، وحالة المحل، وعروض ووظائف.
- كل ما يُعتمد يظهر بالموقع خلال ربع ساعة تقريباً.

## الأمان

القواعد داخل قاعدة البيانات نفسها (`supabase/schema.sql`) ومختبرة آلياً (`tests/supabase.test.ts`):
لا يستطيع أي متصفح نشر منشور أو تغيير حالته أو منح نفسه دور مدير؛ ولا يرى أحد منشورات غيره غير المنشورة،
ولا يعدّل قائمة محل لا يملكه؛ وأرقام الهواتف المخفية وأسماء المرسلين لا تُكشف للعامة؛ وصور الإثبات للمدير فقط.

**ملاحظة:** صور الإعلانات تُرفع إلى مخزن عام بأسماء عشوائية يصعب تخمينها، حتى يستطيع البناء نشرها بعد الموافقة.
صورة إعلان مرفوض لا يُعرف رابطها لأحد، لكنها ليست محمية بكلمة مرور. صور إثبات الملكية في مخزن مغلق تماماً.
