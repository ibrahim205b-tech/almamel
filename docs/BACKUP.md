# النسخ الاحتياطي

كل يوم الساعة ٣:٤١ الفجر، GitHub ياخذ نسخة كاملة من قاعدة البيانات تشمل:
- الإعلانات والمحلات والقوائم والطلبات والديون.
- الدلفري وهوياتهم.
- الشكاوى والتقييمات.

النسخة **تتشفّر بكلمة سر** قبل ما تنحفظ، وتبقى ٣٠ يوم.

بعد النسخ، تشتغل صيانة تلقائية:
- تمسح الصور الي ما يستخدمها أي إعلان، بعد ما يمر عليها ٣ أيام.
- تمسح عناوين IP الأقدم من ٦ أشهر.

## التفعيل (مرة وحدة)

1. **مفتاح الخدمة:** بـ Supabase روح على Project Settings ثم API Keys، وانسخ مفتاح `service_role` أو `sb_secret_...`.
   - ⚠️ هذا المفتاح سري جداً. لا تدزه لأي أحد ولا بالمحادثة.
2. بـ GitHub افتح المستودع وروح على Settings ثم Secrets and variables ثم Actions، واضغط **New repository secret**:
   - الاسم `SUPABASE_SERVICE_KEY` والقيمة المفتاح الي نسخته.
   - الاسم `BACKUP_PASSWORD` والقيمة كلمة سر طويلة (١٢ حرف أو أكثر) **تحفظها عندك**. بدونها ما تكدر تفتح النسخة.
3. للتجربة: روح على Actions ثم Daily backup ثم Run workflow.

## تنزيل نسخة وفتحها

1. روح على Actions ثم Daily backup، واختار آخر تشغيل ناجح، وبعدين نزّل الملف من Artifacts.
2. فك الضغط عن ملف zip الي نزل. يطلعلك ملف ينتهي بـ `.json.gz.enc`.
3. افتحه بهذا الأمر (على ويندوز يشتغل من Git Bash):

```
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in almamel-backup-YYYY-MM-DD.json.gz.enc -out backup.json.gz -pass pass:'كلمة_السر'
gunzip backup.json.gz
```

الناتج ملف `backup.json` بيه كل الجداول. صور الهويات محفوظة بداخله بصيغة base64. لإرجاع البيانات بعد كارثة، دز الملف لـ Claude.
