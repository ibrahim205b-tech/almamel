# محتوى الموقع

- `listings/`: كل إعلان ملف `.md`. أسهل طريقة لإضافة إعلان: افتح صفحة **/publish/** في الموقع، املأ الحقول، واضغط «حفظ في GitHub».
- `images/`: ارفع صور الإعلانات هنا (JPG أو PNG أو WebP، أقل من ٥ ميغابايت)، واكتب أسماءها في الإعلان.
- `settings.yml` (اختياري): تعديل نصوص الموقع، مثل `announcement: "نص شريط التنبيه"`.

بعد أي تغيير يُبنى الموقع ويُنشر تلقائياً خلال دقيقة أو دقيقتين. إذا كان في الملف خطأ، يتوقف النشر ويبقى الموقع السابق كما هو، وتظهر رسالة الخطأ في تبويب **Actions**.
