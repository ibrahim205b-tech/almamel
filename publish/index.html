نشر إعلان على الموقع

هذه الصفحة لصاحب الموقع. تملأ الحقول، فيتجهز ملف الإعلان وتنفتح صفحة GitHub لحفظه. بعد الحفظ بدقيقة أو دقيقتين يظهر الإعلان في الموقع.

لا أحد يقدر ينشر إلا من عنده صلاحية الكتابة على مستودع GitHub. هذه الصفحة تجهّز الملف فقط.

الشارع أو أقرب نقطة دالة
مثال: يومياً من ٩ الصبح لـ ١١ بالليل
إذا عندك توصيل
اسم المحل أو المطعم أو المعمل
مثال: من ٨ الصبح لـ ٤ العصر
الخبرة، الشهادة، العمر...
لا تكتب رقم الدار. يكفي اسم الشارع أو أقرب معلم.
مثال: ١٠ سنوات بصيانة المكيفات
من ١ إلى ٣٠ يوماً
اتركها فارغة إذا الطلب مو تبرع بالدم
مثال: عدد قناني الدم
بدون رقم الردهة أو الغرفة
قريب أو صديق، يظهر حتى يعرف المتبرع مع منو يحچي
كل صنف بسطر: «الاسم | السعر» مثل «تكة لحم | 6000»، أو الصق المنيو بصيغة واتساب: سطر القسم «*المشويات*» ثم «• نفر كباب — 12,000». الأحجام: «• بيتزا: صغير 5,000 / وسط 7,000».
الصور (اختياري، حتى ٦)

    تُصغَّر الصور تلقائياً وتُحفظ مع الإعلان. أول صورة تظهر كصورة رئيسية.

      صور مرفوعة مسبقاً على GitHub (متقدم)
      أسماء ملفات موجودة في مجلد content/images مفصولة بفاصلة: shop.jpg, menu.jpg
      اتركه فارغاً للمدة الافتراضية للقسم

      ملف الإعلان جاهز

      1. اضغط «حفظ في GitHub»، وراح تنفتح صفحة الملف وفيها النص جاهز.
      2. انزل لآخر الصفحة واضغط Commit changes.
      3. بعد دقيقة أو دقيقتين حدّث الموقع.

      الإعلان طويل (مثل منيو كامل)، لذلك تنفتح صفحة الملف فارغة والنص يُنسخ تلقائياً عند الضغط على «حفظ في GitHub». اضغط داخل مربع الكتابة في GitHub والصق النص (Ctrl+V)، ثم اضغط «Commit changes». إذا لم يُلصق شيء اضغط «نسخ النص» هنا أولاً.

      حفظ في GitHub

      لحذف إعلان: افتح ملفه في مجلد content/listings على GitHub واحذفه. لتعديله: عدّل الملف.
